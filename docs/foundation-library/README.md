# Foundation Library

This folder is the VentureOS Foundation Library: the permanent knowledge system for the platform.

Start here: [00-START-HERE.md](./00-START-HERE.md).

The supreme governing document of the repository is the [VentureOS Project Constitution](../PROJECT_CONSTITUTION.md). Before any sprint, implementation, review, refactor, or bug fix, read that constitution, then the [Master Engineering Prompt](../engineering/MASTER_ENGINEERING_PROMPT.md). The [Engineering Index](../engineering/README.md) maps the Foundation Runbook and process standards.

Locked technical specifications remain beside the code and under `docs/foundation/`. This library is how those facts are read, governed, and taught. It does not replace Runtime, IDS, or the Definition Registry as implementation sources of truth.
