# Glossary

**Purpose.** Define Foundation terms so the library stays one language.

**Authority.** Glossary. If a term conflicts with a locked specification, the specification wins and this page must be corrected.

**Audience.** Every reader of the library.

**Dependencies.** [Start Here](../00-START-HERE.md)

**Status.** Approved

**Owner.** Foundation

**Last Updated.** 2026-08-20

---

**Atmosphere** — Layer 2 product headquarters recognition (EAS-001). Not climate. Not implemented as a visual programme yet.

**Capability** — Reusable organisational building block in the Shared Capability Registry. Not a plugin, route, or Runtime.

**Climate** — Executive Light or Executive Dark. Layer 1. Live.

**Company HQ** — The company-as-artefact room of the desk.

**Definition Registry** — The only product-definition system.

**Desk** — Situation Room, Company HQ, and Executive Office as one OS.

**Executive Office** — Seated judgement; leadership floor and executive desks.

**Founder** — The principal of the desk. Copy addresses this person.

**IDS** — IntelligenceOS Design System. Presentation constitution and tokens.

**Product** — What the founder selects at launch. Resolves to a Venture Definition. There is no Product Registry.

**Runtime** — Executive Intelligence Runtime. The only intelligence orchestrator.

**Situation Room** — Daily operating judgement.

**Venture Instance** — A founded company: VIC plus `definition: { id, version }`.

**Venture Intelligence Core (VIC)** — The intelligence document the Runtime runs against.

**VentureOS Company** — Default definition (`ventureos.company@1.0.0`) for founder-created companies.
