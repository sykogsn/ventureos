The Situation Room is where the founder meets the day.

It is not a metrics wall. It projects Runtime intelligence into operating judgement: posture, mission, briefing, health, the call that cannot wait, the portfolio, the company story, and executive memory.

## Surfaces

| Region | Role |
|---|---|
| Header | Page, founder kicker, posture, world line, date |
| Today's Mission | The highest-priority action for the day |
| Executive Briefing | Opportunity, risk, and outcome in one document |
| Operating Health | Cadence of the company, not a traffic light toy |
| Critical Decisions | The founder judgement that is due |
| Portfolio | Companies operated from this workspace |
| Company Story | Highlights the OS already remembers |
| Executive Memory | Decisions that must not be taken twice |

Calviora excludes morning-briefing. The Runtime skips briefing assembly for that instance. The Situation Room must not costume a briefing the definition excluded.

## Empty and loading

An empty desk is a decision waiting to be taken. Copy stays executive. See [Writing Constitution](../03-DESIGN/Writing-Constitution.md).

## Navigation

The Situation Room is wayfinding into Company HQ and the Executive Office. It does not found a company by rendering a card. Founding remains the launch wizard.
