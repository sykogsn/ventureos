# Venture Definitions

Venture Definition Framework documentation.

Authoritative file: `apps/web/src/core/venture-definition/README.md`.

Library: [`docs/foundation-library/02-ARCHITECTURE/Venture-Definitions.md`](../../foundation-library/02-ARCHITECTURE/Venture-Definitions.md).

A definition is metadata. It does not execute. A founded company is a Venture Instance: VIC plus `definition: { id, version }`. IDS brand themes bind to definition ids. They do not alter capability, runtime, or governance profiles.
